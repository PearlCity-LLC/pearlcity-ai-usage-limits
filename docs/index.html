Method

An agent searches public Hacker News (Algolia API) and public X posts. It keeps only posts that name one tool and state a number (percent of a 5-hour window or week, or time to hit a limit), and drops vague or multi-tool posts. “Plan” is only what the poster said. Found a wrong number or want yours counted? Open an issue on GitHub.
